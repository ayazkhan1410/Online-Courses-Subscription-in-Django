# Curated third-party playlists

These playlists are listed in `backend/courses/data/catalog/` and import as
`published` (hidden courses stay hidden on re-seed). Study with Ayaz playlists
are not listed here; they load from `youtube_catalog.json` and publish with the
owner creator. Nothing here is a premium course.

Traversy Media’s React lessons are mostly single crash-course videos. No multi-video playlist URL was verified, so none was added. freeCodeCamp’s Django course is a single video, so Dave Gray’s Django playlist is used instead.

Category slugs: `backend-engineering`, `frontend-engineering`, `python`,
`ai-and-machine-learning`, `devops-and-cloud`, `data-structures-and-interviews`,
`freelancing-and-career`. Catalog seed publishes them for the public library.
